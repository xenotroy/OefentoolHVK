# Een goede en toetsbare RI&E

Openbare kennisgids van Kevin Troy, 21 oktober 2026.

Deze zelfstandige pagina gebruikt HTML, CSS en JavaScript. Er zijn geen externe scripts, trackingdiensten of lettertypen nodig. De volledige openbare tekst staat in `analyse.md`.

De gids bevat algemene voorbeelden en openbare bronlinks. Interne dossiers en persoonsgebonden beoordelingen maken geen deel uit van deze publicatie. De gereedcontrole is een gesprekscheck; zij levert geen nalevingsscore of formele toetsverklaring. Vinkjes worden niet bewaard.

## Gebruik

Open de pagina via GitHub Pages of serveer deze map met een lokale HTTP-server. De analyse blijft zonder JavaScript leesbaar.

## Bijwerken

Werk de openbare inhoud in HTML en Markdown in samenhang bij. Controleer links, mobiele weergave, zoeken, afdrukken en de anonimiteit van voorbeelden voor publicatie.
